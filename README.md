<h1>WiFi Security Analyser</h1>

<h2>Introduction</h2>
<p>
    <strong>WiFi Security Analyser</strong> is an educational cybersecurity project developed using
    <strong>Python</strong> to analyze nearby wireless networks and identify common security risks.
    The project focuses on understanding WiFi security mechanisms and detecting insecure or weakly
    protected networks.
</p>
<p>
    This tool is intended strictly for <strong>ethical and learning purposes</strong>. It should be used
    only on networks owned by the user or with proper authorization.
</p>

<h2>Objectives</h2>
<ul>
    <li>To understand the working of WiFi networks and wireless communication</li>
    <li>To study different WiFi security protocols such as Open, WEP, WPA, WPA2, and WPA3</li>
    <li>To identify insecure or weak WiFi configurations</li>
    <li>To gain practical experience in cybersecurity using Python</li>
    <li>To generate a basic WiFi security assessment report</li>
</ul>

<h2>Features</h2>
<ul>
    <li>Scans nearby WiFi networks</li>
    <li>Identifies SSIDs and security protocols</li>
    <li>Detects open and weakly secured networks</li>
    <li>Performs basic risk analysis</li>
    <li>Generates a readable security report</li>
</ul>
